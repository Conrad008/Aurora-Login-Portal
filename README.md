## Aurora | Login Portal

 This document showcases the login page for a company by the name Aurora
 It is a modern glassmorphic login interface designed with advanced CSS styling and smooth UI animations. The project combines a vibrant animated mesh-gradient background with frosted-glass effects to create a premium futuristic user experience.

 ## Features
 **Animated mesh-gradient background**
 **Glassmorphism login card with backdrop blur**
 **Floating animated decorative blobs**
 **Responsive layout for mobile and desktop**
 **Google Fonts integration**
 **Smooth transitions and hover effects**
 **Glow-effect login button**
 **Rounded modern input fields**
 **Soft shadows and layered depth stylin**

 ## Technologies used
 HTML5
 CSS3
 Flexbox
 CSS Animations
 Google Fonts

## Getting Started

**Prerequisites**
Any modern web browser (Chrome, Firefox, Safari, or Edge).

Installation
1. **Clone the repository:**
   
```bash
   git clone https://github.com/Conrad008/Aurora-Login-Portal
   cd aurora-login-portal
```

2. **Open the project:**
Simply open the index.html file in your preferred browser to view the current build.
